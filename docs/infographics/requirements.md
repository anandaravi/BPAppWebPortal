## Production Notes

- All module hero banners: 1920×1080px minimum, dark overlay applied in code
- Feature section photos: 1200×800px, displayed at `h-80` (320px) in rounded containers
- UI mockups: Build as React components OR export as PNG from Figma/actual BPApp screens
- Architecture diagrams: SVG preferred (scalable, theme-consistent); export from Excalidraw/Figma
- Preferred tools: **Figma** (mockups), **Excalidraw** (diagrams), **Canva** (infographics), actual **BPApp screenshots** (UI mockups)
- Source app for screenshots: `~/development/PapyrusBPApp` — run locally and capture screens
